### 🔍 TruthLoop — AI-Powered Misinformation Literacy Platform

A gamified platform that challenges users to distinguish real information from misinformation.

- Interactive claim voting and nested discussions.
- Gamified engagement and dynamic leaderboards.
- AI-powered personalized misinformation analysis.
- Real-time leaderboard updates using SSE.

<sub>React · TypeScript · TanStack Query · Node.js · Express · PostgreSQL · Claude AI</sub>

[Explore TruthLoop →](https://github.com/Muskanpoddar/Truthloop)

---

### 🛡️ TapGuard — AI Personal Safety Application

An intelligent personal safety application designed to identify potential risks and help users stay connected to trusted contacts.

- Multi-modal risk detection using motion, audio and GPS.
- On-device machine learning with TensorFlow Lite.
- QR/NFC contact pairing and live location sharing.
- Automated SOS alerts and safety check-ins.

<sub>Flutter · Dart · TensorFlow Lite · Firebase · Riverpod</sub>

---

### 🌱 GrowMe — Social Goal Tracking Application

A social platform designed to make personal growth, daily habits and goal achievement more engaging.

- Daily goal creation and progress tracking.
- Community feed and social interactions.
- Firebase authentication and cloud storage.
- Profile management and image-based posts.

<sub>Flutter · Dart · Firebase</sub>

---

### 📄 PDF Tools — Merge, Scan & Edit

An all-in-one PDF utility application built to make document management simple and accessible.

- Merge, compress, scan and edit PDF documents.
- Offline document processing.
- Published on the Google Play Store.
- Reached 1,000+ downloads.

<sub>Flutter · Dart</sub>
